# SOL / MELI — sueldo e ingresos

Workbook canónico: `MELI_Conceptos_2026.xlsx`

## Hojas

- **Ingresos** — netos MELI por **mes de cobro** (no se mezclan con gastos).
- **Conceptos por mes** — detalle de haberes, bonos, SAC, descuentos y LTRP editable.
- **Fuentes** — recibos PDF usados, fechas de pago, conciliación haberes / descuentos / neto.

## Reglas

- El sueldo **no** suma a la matriz `2026` de CIUDAD ni a Almacén.
- Período salarial ≠ mes de cobro: julio se cobra el **01/08**.
- Solo cargar importes que figuren en recibo oficial.
